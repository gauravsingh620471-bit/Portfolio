project case study

Wanderlust — Airbnb Clone

July 2025

OVERVIEW

Wanderlust is a full-stack, Airbnb-inspired listings platform built to practice end-to-end web development — from schema design through a server-rendered, responsive interface.

FEATURES

  • Browse and view property listings with images and details
  • Server-rendered EJS templates for fast, SEO-friendly pages
  • MongoDB-backed data models alongside relational SQL usage
  • Responsive layout built with HTML, CSS and Bootstrap

TECH STACK

CHALLENGES

Coordinating a MongoDB document model alongside SQL-based data and keeping the Express/EJS routing and rendering clean as the number of views grew.

SOLUTIONS

Structured routes and controllers by resource, kept templates modular with EJS partials, and used Postman throughout development to test API endpoints before wiring them to the UI.
